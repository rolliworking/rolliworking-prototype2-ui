# RCA — Build failure for run a4ece8a7-f766-4504-a831-1cce339b97f3 (rollisuite-emergent)

## Summary
The redeploy failed at the **build_image** step. Cloud Build step #2 (`docker-build`) failed in the `frontend-build` stage while running `yarn build`. Root cause is a **TypeScript compile error in app source** — missing icon imports. This is NOT a deployment/manifest problem; the manifests are fine.

## Evidence (from Cloud Build logs)
```
src/components/sales/PickupSessionCard.tsx(30,164): error TS2304: Cannot find name 'Video'.
src/components/sales/PickupSessionCard.tsx(35,289): error TS2304: Cannot find name 'EyeOff'.
src/components/sales/PickupSessionCard.tsx(36,268): error TS2304: Cannot find name 'EyeOff'.
error Command failed with exit code 2.
```
`yarn build` runs `tsc --noEmit && vite build`; `tsc` aborts the build on these errors (exit 2), which surfaces as the `build_image` activity error.

## Root cause
`frontend/src/components/sales/PickupSessionCard.tsx` line 2 imports only two icons from `lucide-react`:
```ts
import { Film, ShieldAlert } from 'lucide-react';
```
but the JSX uses two more icons that are never imported:
- `<Video size={11} />` — line 30 (NVR clip row)
- `<EyeOff size={10} />` and `<EyeOff size={14} />` — lines 35 and 36 (ID-photo captions)

Because `Video` and `EyeOff` are undefined identifiers, `tsc` fails with TS2304.

## Fix (apply in source, frontend/src/components/sales/PickupSessionCard.tsx line 2)
Replace:
```ts
import { Film, ShieldAlert } from 'lucide-react';
```
with:
```ts
import { Film, ShieldAlert, Video, EyeOff } from 'lucide-react';
```

## Verification (performed in eph sandbox on this run's pulled source)
1. Confirmed line 2 imported only `Film, ShieldAlert`, while `<Video>` (L30) and `<EyeOff>` (L35, L36) are used.
2. Applied the import edit above.
3. Ran `yarn install` (success) then `yarn build` — the build completed and produced `frontend/dist/` (fresh `assets/`, `index.html` etc.). Since `vite build` only runs after `tsc --noEmit` passes, the TS2304 errors are resolved.
