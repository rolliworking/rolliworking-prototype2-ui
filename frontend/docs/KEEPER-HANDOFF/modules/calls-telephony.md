## 1. Live call state machine (`calls.ts`)
`LiveCall {callId, phase: 'ringing' | 'live' | 'ended' | 'missed' | 'answered_elsewhere', direction, number, clientId?, startedAt, answeredAt?, answeredBy?, answeredStation?, here?, endedAt?, durationSec?, voicemail?, jobId?, note?, dismissed?}`. Carrier events → `callRinging` → `callAnswered(here | elsewhere)` | `callMissed` → `callEnded`. Subscribe: `subscribeCalls`, `CALLS_EVENT`, `liveCallsSync / liveCallSync / activeCallSync`. Outbound: `startOutboundCall(number, clientId?)` (click-to-call from `PhoneLink` on Client 360 header, job header, directory). Per-call: `setLiveNote`, `setLiveJob`, `dismissLive / undismissLive`, `setDisposition`.

## 2. Screen-pop (`CallPopHost`, top-right card; desktop shell only, **manager tier + concierge role**)
NAME · number · rating **a / b / c** (c = lifetime items) · one xl dot row per **active job newest first** (tap → `/jobs/:id?leg=`) · last contact line (`lastContactLine`) · Open client · Open job ▾ · Note · Page · Answer / Hang up. Click-through collapses to a chip; Esc / X dismisses; "Answered by VC" chip when another station took it. Unknown number → `/clients?new=1&phone=` (`NewClientFromCall`). After hang-up: `DispositionDialog` (`CallDisposition = estimate_discussed | approval_given | status_inquiry | pickup_scheduled | voicemail | missed`); `approval_given` → **PENDING add-on** on the job (`AddOnsPanel` pending → `confirmJobAddon`). `popViewSync(call)` builds the card from `client.ts` reads.
