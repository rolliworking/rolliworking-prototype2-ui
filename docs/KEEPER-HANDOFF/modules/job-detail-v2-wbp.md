## 1. Job page (`/jobs/:id`) — "where is it and where is it in the process"
Left column top → bottom: **Item header** (`ItemHeader`: model · ref · serial · client + rating · status / hold / priority chips · photo strip + lightbox · Request SUB- → submission · Est → estimate · SO; return chips `job-returned-from` / `job-returned-to-*`) → **W·B·P row** (`job-wbp`, every open job of the client, this one outlined + first) → **Process flow** (`ProcessFlow`, `getJobFlow / jobFlowSync → JobFlow {lines: FlowLine[]}`): one line per component (H / B / C with item labels 1/3…), stages `FlowStageKey` Intake → In queue → In progress → QC → Finished; filled dot = status position; **red ring = blocker** (`FlowBlocker`: awaiting approval on Intake, hold / PR awaiting client on the current dot); vendor legs replace In progress with the lane stages (dashed), late vendor red / due ≤ 2 d amber (`getJobVendorLegs`); **custody label comes from the custody record, never from status** (`FlowCustody`; amber **status / custody mismatch** badge); `N / M components finished`; `?leg=` focus from the call pop → **Add-ons since estimate** (`AddOnsPanel`, `getJobAddons → JobAddonsView`: derived = client-approved parts requests + estimate-revision lines after the first send; manual rows `addJobAddon(AddonInput)` flagged + audited; `AddonChannel` / `ADDON_CHANNELS`; phone approvals land **pending** → `confirmJobAddon`) → **Original estimate**, **Inspection report** (collapsed) → **Outsource / concierge** (`OutsourceInfo`, info-only) → **More** (Photos · Parts requests · Messages · Bench tests · Timing · Service evidence · Shop time · Appraisals · Auth photos — collapsed, counts on the first two). Removed from v1: components completion card, verification-chain card, line-items card. Right column unchanged (status actions, holds, notes, summary draft, calls line).

## 3. Component-scoped holds (D-428)
`JobHold.component?: ComponentKey` — a parts / outsource hold scoped to one leg reds **only that leg** everywhere (job flow, staff dots, portal dots); `HoldModal` scope row; `holdBlocks(j, key)` / `canCompleteComponent`. Undefined = whole job (default).
